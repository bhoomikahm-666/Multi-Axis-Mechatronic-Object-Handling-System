# Multi-Axis Mechatronic Object Handling System

An ESP32-based Wi-Fi-controlled mobile robot integrated with a four-servo robotic arm for remote navigation and pick-and-place operations.

## Project Overview

This project combines mobile robotics, embedded systems and IoT-based control to demonstrate remote navigation and object handling through a smartphone interface.

## Objectives

- Develop a Wi-Fi-controlled mobile robotic platform.
- Implement remote movement control using ESP32.
- Integrate a four-servo robotic arm for object handling.
- Enable coordinated mobile navigation and pick-and-place operations.

## Hardware Components

- ESP32 microcontroller
- Four-wheel robotic chassis
- DC gear motors
- L298N motor driver
- Four servo motors
- Battery power supply
- Buck converter

## Technologies Used

- Arduino IDE
- Embedded C/C++
- ESP32 and Wi-Fi
- Blynk IoT
- PWM-based motor and servo control

## System Working

1. The user sends commands through the Blynk mobile interface.
2. The ESP32 receives commands over Wi-Fi.
3. The L298N motor driver controls the mobile platform's DC motors.
4. The ESP32 controls the robotic arm's servo motors.
5. The robot performs remote navigation and pick-and-place operations.

## Key Features

- Wireless robot control
- Smartphone-based interface
- Four-wheel mobile navigation
- Four-servo robotic arm
- Remote pick-and-place operation
- Embedded hardware and software integration

The project demonstrates remote robot navigation and robotic arm positioning through the Blynk interface. Project documentation includes the system block diagram, circuit diagram, control flowchart and available demonstration images.
